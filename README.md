# ShopNest - Full-Stack E-Commerce Application 🛒

A feature-rich, fully responsive e-commerce web application featuring modern user experiences and a secure management backend.

## 🚀 Features
- **Responsive UI:** Clean and intuitive user interfaces built for all screen sizes.
- **User Authentication:** Secure user signup and login utilizing JSON Web Tokens (JWT).
- **Product & Order Management:** Fully functional RESTful APIs handling cart operations, product catalogs, and order creation.

## 🛠️ Tech Stack
- **Frontend:** React.js, Tailwind CSS, Bootstrap
- **Backend:** Node.js, Express.js
- **Database:** MongoDB, Mongoose
- **Version Control:** Git & GitHub

## 💻 How to Run Locally
1. Clone the repository: `git clone https://github.com`
2. Install dependencies for both backend and frontend: `npm install`
3. Run the development server: `npm run dev`
